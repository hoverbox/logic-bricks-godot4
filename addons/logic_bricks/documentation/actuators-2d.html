Chapter guide

Building 2D actions

These actions are grouped exactly like the 2D right-click menu and use 2D node types and Vector2-based values where appropriate.

  1. Select a supported 2D node.
  2. Choose the matching right-click submenu.
  3. Verify the target node and coordinate values before adding more logic.
2D WORKFLOW

2D Setup and Actions

Use this section for Node2D-based scenes. The documentation categories below mirror the action submenus displayed when a supported 2D node is selected.

1

Select a 2D node

Select a Node2D, CharacterBody2D, RigidBody2D, Camera2D, AnimatedSprite2D, or another supported 2D node.

2

Open Logic Bricks

The editor switches to the 2D brick domain and shows common bricks together with compatible 2D-specific bricks.

3

Use 2D values

Position and movement use Vector2 values. Rotation is expressed around the 2D axis, and 2D camera actions target Camera2D nodes.

4

Choose by submenu

Use the category links below to jump to the same submenu organization used by the right-click menu.

How this relates to the menu

The 2D menu substitutes its own Sprite Animation and Tween bricks for the generic 3D Animation entries, which are not shown for 2D nodes.

Sprite Animation

2D

Play, stop, or pause AnimatedSprite2D animations. Leave Target Node empty to use the node this script is on.

Menu Right-click → Actions → Animation

Options

Property Details
mode Mode
Choices: Play, Stop, Pause
Default: Play
Play: start or resume the animation.
Stop: stop playback and reset.
Pause: freeze at the current frame.
animation_name Animation Name
Name of the animation in the AnimatedSprite2D SpriteFrames resource. Leave blank to play the default/current animation.
speed_scale Speed Scale
Default: 1.0
Playback speed multiplier. Accepts a number, variable, or expression.
target_node Target Node
Name of the AnimatedSprite2D node to control. Leave empty to target self.
Using this brick

Typical uses

  • Switch AnimatedSprite2D animations such as idle, run and jump.
  • Change the playback speed for slow-motion or fast effects.

Example chain

Input → Gate → Sprite Animation
Tip Leave Target Node empty when the bricks are on the AnimatedSprite2D itself.
Common mistake Restarting the same animation every frame. Play it from a trigger that changes, or use states.

Tween

2D

Animates any property on self or on a node found by name anywhere in the current scene tree.

Menu Right-click → Actions → Animation

Options

Property Details
target_mode Target Mode
Choices: Self, Node
Default: Self
Self: tween a property on this node.
Node: find a node by name and tween a property on it.
target_node_name Target Node Name
Node mode only. Literal Node Name: type the target node name. String Variable: type the name of a String variable that stores the node name.

Choices: Literal Node Name, String Variable
Default: literal
Literal Node Name: use Target Node Name directly.
String Variable: treat Target Node Name as a variable name and read that String at runtime.
export_node_name Export Node Name
Default: false
Literal mode only. Adds an @export String to the generated script so the node name can be edited in the Inspector without exposing a node reference.
property Property
Default: modulate:a
Property path to animate. Examples: modulate:a, position:y, scale, size.
target_value Target Value
Default: 0.0
End value. Accepts a number, Vector2(...), Vector3(...), Color(...), or variable.
duration Duration
Default: 0.5
Animation duration in seconds. Accepts a number or variable.
trans_type Trans Type
Choices: Linear, Sine, Quint, Quart, Quad, Expo, Elastic, Bounce, Back, Spring, Circular, Cubic
Default: Linear
Easing curve shape.
ease_type Ease Type
Choices: In, Out, In Out, Out In
Default: In Out
Which part of the curve to apply easing to.
loop Loop
Default: false
Repeat the tween indefinitely.
Using this brick

Typical uses

  • Smoothly move, scale, rotate or fade a node, such as a menu sliding in or a door opening.
  • Animate any property by name, such as modulate:a for fading.

Example chain

Collision 2D → Gate → Tween
Tip Choose a Trans Type such as Back or Elastic for a more lively motion.
Common mistake Starting the tween every frame from a trigger that stays active, so it keeps restarting.

2D Audio

3D 2D

Play 2D/UI audio from a file. Creates its own AudioStreamPlayer at runtime — no @export needed.

Menu Right-click → Actions → Audio

Options

Property Details
mode Mode
Choices: Play, Stop, Pause, Fade In, Fade Out
Default: Play
Play, Stop, Pause, Fade In, or Fade Out.

Audio file to play. Supports .wav, .ogg, .mp3.

Choices: AudioStreamPlayer, AudioStreamPlayer2D
Default: stream_player
AudioStreamPlayer: non-positional (music, UI sounds).
AudioStreamPlayer2D: positional in 2D space.
play_mode Play Mode
Choices: Restart, Overlap, Ignore If Playing
Default: Restart
Restart: stop and restart if already playing.
Overlap: spawn a new player each time.
Ignore: do nothing if already playing.
volume Volume
Range: -80 to 24
Default: 0.0
Volume in dB. 0 = mixer-neutral, lower values reduce volume, -80 = silent.
pitch Pitch
Range: 0.01 to 4.0
Default: 1.0
Pitch multiplier. 1.0 = normal.
pitch_random Pitch Random
Range: 0.0 to 1.0
Default: 0.0
Random pitch variation ± this amount each play.
loop Loop
Default: false
Replay the sound again when it finishes.
audio_bus Audio Bus
Audio bus name. Leave empty for Master.
fade_duration Fade Duration
Range: 0.1 to 10.0
Default: 1.0
Duration of fade in/out in seconds.
Using this brick

Typical uses

  • Play non-positional sounds: UI clicks, pickups, jingles.
  • Add Pitch Random so repeated sounds don't feel robotic.

Example chain

Collision → Gate → 2D Audio
Tip Use Overlap for rapid sounds such as gunfire, and Ignore If Playing for sounds that shouldn't stack.
Common mistake Playing a sound from Always, which restarts it every frame.

Music

3D 2D UI

Three modes:

  • Tracks: define and create music players at startup.
  • Set: set which track is current (and optionally play it).
  • Control: play, stop, pause, resume, or crossfade from current to another track.
Menu Right-click → Actions → Audio

Options

Property Details
music_mode Music Mode
Choices: Tracks, Set, Control
Default: Tracks
Tracks: set up your music files.
Set: choose the active track.
Control: control playback.
tracks Tracks
Default: []
Music files to preload. Track 0 is first, Track 1 second, etc.
volume_db Volume Db
Range: -80 to 24
Default: 0.0
Default volume in dB for all tracks.
loop Loop
Default: true
Loop all tracks.
audio_bus Audio Bus
Audio bus for all tracks. Leave empty for Master.
persist Persist
Default: false
Keep music playing when the scene restarts or changes.
Players are moved to GlobalVars so they survive scene transitions.
set_track Set Track
Default: 0
Which track index to make current.
Accepts a number (0, 1, 2…) or a variable name.
With a literal number, fires once and stays. With a variable, switches track whenever the variable changes.
set_play Set Play
Default: true
Also start playing the track when setting it as current.
control_action Control Action
Choices: Play, Stop, Pause, Resume, Crossfade
Default: Play
Play: start the current track.
Stop: stop the current track.
Pause: freeze the current track.
Resume: continue the current track.
Crossfade: fade out current track and fade in the target track.
to_track To Track
Default: 1
Track index to crossfade into.
Accepts a number (1, 2…) or a variable name.
With a literal number, fades once per trigger. With a variable, a new crossfade starts automatically whenever the variable changes.
crossfade_time Crossfade Time
Range: 0.1 to 10.0
Default: 1.0
Crossfade duration in seconds.
Using this brick

Typical uses

  • Set up level music once with Tracks, then switch with Set.
  • Crossfade to battle or boss music and back.

Example chain

Signal Receive → Gate → Music
Tip Define tracks once (for example on the level root at start), then control them from anywhere.
Common mistake Running Tracks mode more than once. It creates the music players; use Set or Control afterwards.

Preload

3D 2D

Preloads resources (materials, scenes, textures, audio, meshes) into memory before they are needed, preventing runtime hitches and frame drops.

Menu Right-click → Actions → Game

Options

Property Details
load_mode Load Mode
Choices: Background (Threaded), Immediate (Blocking)
Default: background
Background: loads on a thread without blocking gameplay (recommended). Immediate: blocks the main thread until done — use only on loading screens.
resource_type Resource Type
Choices: Any, Scene, Material, Texture, AudioStream, Mesh, Shader
Default: Any
Filter hint for the file picker. Choose 'Any' to mix resource types freely.
resources Resources
Default: []
List of resource paths to preload. Add as many as needed.
on_complete_signal On Complete Signal
Default: true
When all resources finish loading, send a message to a group. Useful to hide loading screens or trigger the next event.
signal_group Signal Group
Shown when On Complete Signal is on.
The node group that will receive the completion message.
signal_message Signal Message
Default: preload_done
Shown when On Complete Signal is on.
The message string sent to the group when loading is complete.
Using this brick

Typical uses

  • Load heavy scenes, materials or sounds during a loading screen to avoid hitches later.
  • Send a signal when loading finishes to continue.

Example chain

Always → Gate → Preload

Hit Stop

3D 2D

Briefly pauses or slows game time when an impact lands. Use for attacks, damage, blocks, heavy landings, and breaks. This is also called hit pause or impact freeze.

Menu Right-click → Actions → Game Feel

Options

Property Details
preset Preset
Choices: Tiny, Light, Medium, Heavy, Custom
Default: Medium
Starting feel for the hit stop.
Tiny: subtle tap.
Light: small hit.
Medium: normal attack impact.
Heavy: big hit or explosion.
Custom: use your own Duration and Time Scale values.
duration Duration
Default: 0.06
How long the stop lasts in real seconds.
Typical values are 0.03 to 0.12 seconds.
Accepts a number, variable, or expression.
time_scale Time Scale
Default: 0.0
How frozen the game becomes during hit stop.
0.0 = full freeze.
0.05 = almost frozen.
0.2 = slow motion instead of a hard freeze.
Accepts a number, variable, or expression.
restart_if_active Restart If Active
Default: false
Off: ignore repeated triggers while hit stop is already running.
On: a new hit can restart/replace the current hit stop.
Using this brick

Typical uses

  • Freeze the game for a split second when an attack lands.
  • Emphasize heavy landings, blocks or breaking objects.

Example chain

Collision → Gate → Hit Stop
Tip Start with the Light preset; heavier presets are best saved for big moments.

strong_motor Strong Motor
Range: 0.0 to 1.0
Default: 0.5
Low-frequency motor (0–1). Used for heavy impact feedback.
duration Duration
Default: 0.5
How long to vibrate in seconds (Vibrate mode only).
pattern Pattern
Choices: Single Pulse, Double Pulse, Sustained, Ramp Up, Ramp Down, Heartbeat

Single Pulse: one short hit — landing, collecting item.

Surface Attachment

3D 2D

Attach to a physically touching surface, or detach. Supports rigid bodies and characters in 3D and 2D. Use a Collision or Surface Check trigger to choose when to attach.

Menu Right-click → Actions → Physics

Options

Property Details
mode Mode
Choices: Attach, Detach
Default: Attach
Attach: stick to a touching physics body. Detach: release and resume normal movement.
align_to_surface Align To Surface
Default: false
Rigid bodies: point local -Z (3D) or +X (2D) into the surface. Leave off to keep orientation.
surface_offset Surface Offset
Range: 0 to 10000
Default: 0.0
Extra gap outward from the current contact position. World units in 3D; pixels in 2D.
follow_surface Follow Surface
Default: true
Follow the attached surface's movement and rotation. Off: hold the attachment in world space.
allow_movement Allow Movement
Default: false
Characters: allow existing movement bricks to move along the surface. Gravity is suspended while attached. Leaving the surface releases the character.
balance_assist Balance Assist
Default: false
3D characters: gently guide movement toward a railing's center Path. Requires Allow Movement. Steering remains available; strength 1 removes sideways input.
balance_path Balance Path
Choose a Path3D along the railing's center. For moving railings, make the Path a child of the railing. The curve needs at least two points.
balance_strength Balance Strength
Range: 0 to 1
Default: 0.75
0: no assistance. Higher values reduce sideways drift and pull toward the center more strongly. Default 0.75; try 1 for a thin railing.
push_off_speed Push Off Speed
Range: 0 to 10000
Default: 0.0
Characters: speed away from the surface when detaching. 0 releases without a push. World units/sec in 3D; pixels/sec in 2D.

  • Stick to walls, ceilings or moving objects, such as a grappling hook or wall climbing.
  • Ride a moving surface with Follow Surface on.
