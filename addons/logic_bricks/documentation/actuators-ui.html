Chapter guide

Building UI actions

UI actions work with Control-based interfaces and are listed in the same flat menu structure used by the addon.

  1. Select the relevant UI node.
  2. Choose the action that changes or controls the interface.
  3. Trigger it from input, variables, signals, or other triggers.
UI WORKFLOW

UI Setup and Actions

Use this section for Control-based interfaces. Unlike the longer 3D and 2D lists, the addon intentionally displays compatible UI actions as one flat menu.

1

Select a Control node

Select a Control, Button, Label, Slider, ProgressBar, TabContainer, Window, or another supported UI node.

2

Open Logic Bricks

The addon keeps triggers and gates available, but filters actions to the UI-compatible set.

3

Target interface nodes

Many UI actions can act on the selected node or locate another interface node by name, depending on the brick.

4

Build interaction chains

Connect input or UI triggers to gates and then to focus, text, visibility, popup, slider, tab, window, or other UI actions.

How this relates to the menu

The UI action menu is flat by design, so this page uses one linked action reference rather than artificial submenus.

2D Audio

UI

Play 2D/UI audio from a file. Creates its own AudioStreamPlayer at runtime — no @export needed.

Menu Right-click → Actions

Options

Property Details
mode Mode
Choices: Play, Stop, Pause, Fade In, Fade Out
Default: Play
Play, Stop, Pause, Fade In, or Fade Out.
sound_file Sound File
File: *.wav,*.ogg,*.mp3
Audio file to play. Supports .wav, .ogg, .mp3.
player_type Player Type
Choices: AudioStreamPlayer, AudioStreamPlayer2D
Default: stream_player
AudioStreamPlayer: non-positional (music, UI sounds).
AudioStreamPlayer2D: positional in 2D space.
play_mode Play Mode
Choices: Restart, Overlap, Ignore If Playing
Default: Restart
Restart: stop and restart if already playing.
Overlap: spawn a new player each time.
Ignore: do nothing if already playing.
volume Volume
Range: -80 to 24
Default: 0.0
Volume in dB. 0 = mixer-neutral, lower values reduce volume, -80 = silent.
pitch Pitch
Range: 0.01 to 4.0
Default: 1.0
Pitch multiplier. 1.0 = normal.
pitch_random Pitch Random
Range: 0.0 to 1.0
Default: 0.0
Random pitch variation ± this amount each play.
loop Loop
Default: false
Replay the sound again when it finishes.
audio_bus Audio Bus
Audio bus name. Leave empty for Master.
fade_duration Fade Duration
Range: 0.1 to 10.0
Default: 1.0
Duration of fade in/out in seconds.
Using this brick

Typical uses

  • Play non-positional sounds: UI clicks, pickups, jingles.
  • Add Pitch Random so repeated sounds don't feel robotic.

Example chain

Button → Gate → 2D Audio
Tip Use Overlap for rapid sounds such as gunfire, and Ignore If Playing for sounds that shouldn't stack.
Common mistake Playing a sound from Always, which restarts it every frame.

Animation

3D UI

Play, stop, or control animations by name. Automatically finds the AnimationPlayer that owns the animation. Works with AnimationPlayers nested at any depth.

Menu Right-click → Actions

Options

Property Details
mode Mode
Choices: Play, Stop, Pause, Queue
Default: Play
Play: start/control an animation
Stop: stop playback
Pause: freeze at current frame
Queue: play after current finishes
animation_name Animation Name
Choices: animations found in the scene (click ↻ to load them)
Name of the animation to play.
playback_mode Playback Mode
Choices: Use Animation Setting, Play Once, Loop, Ping-Pong, Flipper
Default: Use Animation Setting
Shown when Mode is Play.
Use Animation Setting: preserve the Animation resource loop setting.
Play Once: plays once per trigger activation.
Loop: repeats while triggered.
Ping-Pong: repeats forward and backward while triggered.
Flipper: plays forward while triggered and reverses toward the start when released.
trigger_end Trigger End
Choices: Play to End, Stop
Default: Play to End
Shown when Mode is Play.
What happens when the trigger turns off.
Play to End: finish the current pass before stopping.
Stop: stop immediately.
Flipper always reverses when released, so this setting is ignored for Flipper.
speed Speed
Default: 1.0
Playback speed. Accepts:
• A number: 1.0
• A variable: move_speed
• An expression: move_speed * 2
blend_time Blend Time
Default: -1.0
Blend time in seconds (-1 = use default).
Smooth transition from previous animation.
priority Priority
Range: 0 to 100
Default: 0
Shown when Mode is Play.
Animation priority. Higher numbers override lower numbers while the higher-priority animation is still playing.
Example: Walk = 0, Jump = 10.
play_backwards Play Backwards
Default: false
Shown when Mode is Play.
Start playback in reverse. Flipper controls direction automatically.
from_end From End
Default: false
Shown when Mode is Play.
Start from the last frame. Flipper controls its own start/end behavior.
Using this brick

Typical uses

  • Play a door, chest or attack animation from an AnimationPlayer.
  • Queue animations to play one after another, or play an animation backwards to close something.

Example chain

Collision → Gate → Animation
Tip Click ↻ next to Animation Name to load the animations from the scene.
Common mistake Restarting the animation every frame from a trigger that stays active. Use Just Pressed or a one-shot trigger.

Get Variable

3D 2D UI

Reads a variable/property from self, another node, or GlobalVars, then stores it as a local variable that later bricks can use. Useful for UI health bars, ammo labels, score text, and timers.

Menu Right-click → Actions

Options

Property Details
source Source
Choices: Self, Node Name, GlobalVars
Default: Node Name
Self: read from this node.
Node Name: search the current scene for a node with this name.
GlobalVars: read from the GlobalVars autoload.
source_node_name Source Node Name
The name of the node to read from when Source is Node Name. Example: Player.
variable_name Variable Name
The variable/property to read from the source. Example: health, ammo, score.
store_as Store As
The local variable name to store the value in. Later bricks can use this name. Example: current_health.
fallback_value Fallback Value
Optional value to use if the source or variable cannot be found. Leave blank to keep the previous value.
Using this brick

Typical uses

  • Copy the player's health into a local variable for a health bar.
  • Read a value from GlobalVars or another node for later bricks.

Example chain

Always → Gate → Get Variable
Tip Set a Fallback Value so later bricks still work if the source isn't found.
Common mistake Reading from a node name that doesn't exist; the fallback value is used instead.

Modify Variable

3D 2D UI

Modifies a variable's value. Works with local and global variables. Automatically uses GlobalVars if not found locally.

Array modification When variable_name matches an Array variable, the Mode menu changes automatically. Add Item appends an item, Remove Item removes the matching value, Remove At Index removes an item by position, Set Item At Index replaces an item at a position, and Clear removes all items. Copy makes an independent copy of an Array rather than sharing the same Array reference.
Prevent duplicate items Use a Compare Variable trigger set to Does Not Contain before a Modify Variable action set to Add Item. The action will only run when the item is not already in the Array.
Menu Right-click → Actions

Options

Property Details
variable_name Variable Name
Name of the variable to modify. Type a name or choose an existing local/global variable from the dropdown.
mode Mode
Choices: Assign, Adjust By, Copy, Toggle
Default: Assign
Number: Assign, Adjust By, Copy, Toggle
String: Replace, Add Before, Add After, Copy
Array: item operations, Assign, Copy
value Value
Value used by the selected operation. String values are plain text — do not add quotation marks. Numeric values can use variables or math expressions (for example: MinSpeed * 2).
source_variable Source Variable
Source variable name (Copy mode only). Type a name or choose an existing variable from the dropdown.
item_type Item Type
Choices: bool, int, float, String, Vector2, Vector3
Default: String
index Index
Default: 0
Position in the array (0 = first item). Accepts a number, a variable, or math (for example: count - 1).
Using this brick

Typical uses

  • Add score, subtract health or toggle a flag.
  • Add and remove inventory items in an Array variable.

Example chain

Collision → Gate → Modify Variable
Tip Use Adjust By with a negative value to subtract.
Common mistake Adjusting a value from a trigger that stays active, so it changes every frame.

Music

3D 2D UI

Three modes:

  • Tracks: define and create music players at startup.
  • Set: set which track is current (and optionally play it).
  • Control: play, stop, pause, resume, or crossfade from current to another track.
Menu Right-click → Actions

Options

Property Details
music_mode Music Mode
Choices: Tracks, Set, Control
Default: Tracks
Tracks: set up your music files.
Set: choose the active track.
Control: control playback.
tracks Tracks
Default: []
Music files to preload. Track 0 is first, Track 1 second, etc.
volume_db Volume Db
Range: -80 to 24
Default: 0.0
Default volume in dB for all tracks.
loop Loop
Default: true
Loop all tracks.
audio_bus Audio Bus
Audio bus for all tracks. Leave empty for Master.
persist Persist
Default: false
Keep music playing when the scene restarts or changes.
Players are moved to GlobalVars so they survive scene transitions.
set_track Set Track
Default: 0
Which track index to make current.
Accepts a number (0, 1, 2…) or a variable name.
With a literal number, fires once and stays. With a variable, switches track whenever the variable changes.
set_play Set Play
Default: true
Also start playing the track when setting it as current.
control_action Control Action
Choices: Play, Stop, Pause, Resume, Crossfade
Default: Play
Play: start the current track.
Stop: stop the current track.
Pause: freeze the current track.
Resume: continue the current track.
Crossfade: fade out current track and fade in the target track.
to_track To Track
Default: 1
Track index to crossfade into.
Accepts a number (1, 2…) or a variable name.
With a literal number, fades once per trigger. With a variable, a new crossfade starts automatically whenever the variable changes.
crossfade_time Crossfade Time
Range: 0.1 to 10.0
Default: 1.0
Crossfade duration in seconds.
Using this brick

Typical uses

  • Set up level music once with Tracks, then switch with Set.
  • Crossfade to battle or boss music and back.

Example chain

Signal Receive → Gate → Music
Tip Define tracks once (for example on the level root at start), then control them from anywhere.
Common mistake Running Tracks mode more than once. It creates the music players; use Set or Control afterwards.

Choices: the Target Node's Inspector properties
Properties are read directly from the selected target node's Inspector property list.

Value to assign. Numbers, booleans, vectors, colors, variables, and expressions can be entered directly. Plain text is automatically quoted for String properties.
