Documentation

The Documentation button in the Logic Bricks header opens the manual bundled with the add-on in your normal web browser. The bundled manual uses local files, so the documentation remains available without an internet connection.

Jump directly to a brick Right-click a specific brick name in the Add menu, such as Always or Input, then choose View Documentation from the small context menu. The brick is not added to the graph. You can use the same View Documentation command by right-clicking a brick already on the graph. Documentation opens directly to that brick's section, using the 2D, 3D, or UI reference that matches the node you are editing.

Dragging nodes into brick fields

Node-reference fields can be filled without typing the node name. Hold Ctrl (or Cmd on macOS), drag a node from the Scene dock, and drop it directly onto a compatible field in a trigger or action. Logic Bricks stays on the node you are programming while you drag.

Example For a camera-relative Position action, hold Ctrl and drag the Camera3D node from the Scene dock onto the Camera Name field. The field is filled automatically. Specialized fields reject incompatible node types.

Apply Code

Apply Code writes the graph into the node's script as generated code. Besides the code itself, it does three things:

  • Version stamp. The generated block starts with # Generated by Logic Bricks followed by the add-on version that made it. See Updating the add-on.
  • Graph backup. One compressed comment line stores the whole graph. See Graph backup.
  • Required project settings. Some bricks need a project setting to work smoothly. For example, Mouse Look and the 3rd Person Camera need Physics → Common → Physics Interpolation. Apply Code turns such settings on in Project Settings and shows a notice. Restart a running game afterwards. Generated scripts never change engine settings while the game runs.

Graph backup

The graph itself is stored in the scene, on the node. If that data is lost (the node was deleted and re-created, the scene was reverted, or the script was attached to a new node), select the node and choose Options → Sync Bricks from Script. Logic Bricks restores the graph exactly as it was at the last Apply Code: bricks, connections, layout, frames, variables and states. The restore can be undone.

The backup is the line starting with # LB_GRAPH_SNAPSHOT_V1 inside the generated block. Leave it in place. To stop writing it, turn off Project Settings → Logic Bricks → Backup → Save Graph In Script (logic_bricks/backup/save_graph_in_script). Scripts without a backup can still be rebuilt from the generated code, but the layout, frames and other editor-only details may not come back exactly.

Renaming nodes

Bricks refer to other nodes by name (for example the camera of a 3rd Person Camera or the target of Save / Load). When you rename a node in the Scene dock, every brick in the scene that pointed to the old name is updated to the new one, and a notice lists the nodes that changed. Press Apply Code on those nodes so their scripts use the new name too.

  • Nothing is changed when another node in the scene still has the old name, because the bricks may have meant that node. A warning explains this.
  • Renaming a node inside a scene that other scenes instance (for example renaming Gun inside turret.tscn) updates the bricks in those other scenes the next time each of them is opened in the editor.

Updating the add-on

  1. Close any Logic Bricks scripts that are open in the Script editor. An open copy can be saved over the new file.
  2. Replace the addons/logic_bricks folder, then restart the project, or choose Project → Tools → Reload Logic Bricks. Logic Bricks also reloads itself when it notices that it was updated while the editor was open.
  3. Press Apply Code on each node with bricks so its script is regenerated with the new version. Scripts keep their old generated code until you do.

When the selected node's code was made by a different version, a ⚠ Code from … notice appears next to Apply Code. To check a whole project (for example, a class's projects after an update), choose Options → Find Outdated Scripts. It lists every script with Logic Bricks code from another version.

Side panel

The side panel contains Variables, Globals, States, and Frames. Frames support a title, description, color, and adjustable size.
