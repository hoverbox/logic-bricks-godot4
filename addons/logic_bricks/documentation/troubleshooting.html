Logic Bricks Manual

Troubleshooting

Resolve missing bricks, inactive chains, target errors, and processing warnings.

◷ 3 min read Phase 5 enhanced

A brick is missing

Brick menus are built from the runtime registry and may be filtered by the selected node domain. Confirm that the correct 3D, 2D, or UI node is selected.

A chain does not run

  1. Confirm the trigger can become active.
  2. Check the Gate logic mode and state assignment.
  3. Confirm the action targets a valid node and uses the correct node type.
  4. Enable per-brick debugging and inspect the runtime debugger.

Timing and physics warnings

A chain that mixes physics movement with timing-sensitive animation, UI, audio, or other time-based actions can be assigned to physics processing. Split timing-sensitive actions into a separate chain when the addon warns about this combination.

Errors after updating the add-on

Errors such as Nonexistent function '…' in base 'Nil' right after replacing the add-on mean the editor is still running parts of the old version. Choose Project → Tools → Reload Logic Bricks, or restart the project. Then press Apply Code on nodes with bricks; Options → Find Outdated Scripts lists the ones that still need it.

If a fix seems to disappear after an update, an add-on script that was open in the Script editor may have been saved over the new file. Close add-on scripts before updating, and replace the folder again.

The bricks are gone but the script still has code

Select the node and choose Options → Sync Bricks from Script. The graph is restored from the backup saved by the last Apply Code. See Graph backup.

A brick stopped finding a node after a rename

Bricks are updated automatically when you rename a node, but the script keeps the old name until you press Apply Code. If the notice says the bricks were not updated, another node still uses the old name. Rename that node or fix the brick field. See Renaming nodes.

Mouse look or the 3rd person camera stutters

Both rely on Project Settings → Physics → Common → Physics Interpolation. Apply Code turns it on when Enable Physics Interpolation (Mouse) or Smooth Physics Motion (3rd Person Camera) is checked. Restart the running game after it changes. Keep the camera's Physics Interpolation Mode at Inherit or On. Tearing that appears on only one monitor is usually a display or V-Sync issue, not the bricks.

The 3rd person camera goes through walls or zooms in for small objects

Turn on Avoid Walls and make sure the walls are on a layer in Collision Mask. If the camera pulls in for pillars, posts or props, raise Narrow Obstacle Width or put those objects on a layer that is not in Collision Mask. See 3rd Person Camera.
