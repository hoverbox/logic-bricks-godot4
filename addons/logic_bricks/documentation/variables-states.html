Variables, States & Frames

Store values, control active logic, and organize large graphs.

◷ 1 min read Phase 5 enhanced

Variables and globals

Use local variables for data tied to the selected node and globals for data shared across systems. Variable types include Boolean, Integer, Float, String, Vector2, Vector3, and Array values. Vector2 and Vector3 are edited with separate axis fields.

An Array stores an ordered list of items in one variable. Array items may use different supported types, so one Array can contain numbers, strings, booleans, Vector2 values, and Vector3 values. Use the Array editor to add or remove items and choose the type and value for each item.

Array indexes start at 0 The first item is index 0, the second item is index 1, and so on. Compare Variable and Modify Variable automatically detect when the named variable is an Array and change their available operations to Array-specific options.

Variables and math in number fields

Every number field on a brick accepts a plain number, a variable name, or math. For example, a Proximity trigger's Distance can be 5, detect_range, or detect_range * 2, and a Teleport action's X can be spawn_x + 10. The value is worked out each time the brick runs, so changing the variable while the game runs changes what the brick does.

Start typing a name to get suggestions from your local and global variables. If a name looks like a misspelling of one of your variables (or differs only in capitalization), a warning under the field names the variable you probably meant. Plain numbers are kept within the field's allowed range when you leave the field. Variables and math are not limited, so keep their values sensible (for example, a Chance of 0 to 100).

States

States group logic so only the intended state runs. The Gate brick includes state selection and an All States option.

Use View State above the graph to focus on one state's chains, or choose All to see the complete graph. Shared bricks, dependent gates, and All States chains remain visible. Unconnected bricks stay visible while you build. New gates use the state you are viewing. Filtering changes only the editor view; hidden bricks and connections still save and generate code normally. Switching scene nodes resets the view to All.

Frames

Frames visually organize groups of bricks. The current editor supports frame names, comments, colors, dimensions, navigation from the frame list, and deletion.

Organization tip Use frames for readability and states for runtime behavior. They solve different problems.
